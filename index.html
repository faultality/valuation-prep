🚀 Big4 Valuation Survival Kit

Тренажер для экспресс-подготовки к тесту (M&A / Valuation / FinMod)

📊 Мультипликаторы (Золотое правило)

EV (Стоимость бизнеса) сочетается с показателями ДО выплаты процентов (EBITDA, EBIT, Revenue, Unlevered FCF).
Equity Value (Цена акций / P) сочетается с показателями ПОСЛЕ процентов (Net Income, Levered FCF, Book Value).
🚨 ЛОВУШКА: EV / Net Income — НЕВЕРНО! (Двойной учет долга).
EV = EqV + Debt - Cash + Min. Int. + Pref. Stock

💰 Денежные потоки (FCF)

FCFF = EBIT * (1 - t) + D&A - CapEx - ΔNWC
ΔNWC (Изменение оборотного капитала):
Рост Активов (Дебиторка, Запасы) = ОТТОК (-)
Рост Обязательств (Кредиторка) = ПРИТОК (+)
FCFE = FCFF - Проценты*(1-t) - Погашение долга + Новый долг

📉 Ставки дисконтирования

CAPM: Ke = Rf + β * (Rm - Rf)
WACC = Ke*(E/V) + Kd*(1-t)*(D/V)
Налоговый щит (1-t): Проценты по долгу уменьшают налог, поэтому долг дешевле собственного капитала.
Правило: FCFF дисконтируем по WACC (получаем EV). FCFE дисконтируем по Ke (получаем EqV).

🏢 Подходы к оценке

1. Сравнительный (Relative): Comps (биржа), Precedent Transactions (сделки M&A). Обычно Trans. > Comps из-за премии за контроль.
2. Доходный (Intrinsic): DCF. Зависит от допущений. Терминальная стоимость = 60-80% от EV.
3. Затратный (Asset-based): NAV, Ликвидационная. Для банков, недвижимости, банкротов.

Что будет с EV и EqV,
если компания выпустит долг на 100 и положит на счет?
EV не изменится (+100 Долг, -100 Кэш в формуле сократятся).
EqV не изменится (это просто обмен бумаг на кэш внутри компании).
Почему Precedent Transactions
обычно дают оценку ВЫШЕ, чем Public Comps?
Из-за Control Premium (Премия за контроль). Покупатель платит больше, чтобы получить 100% голосов и синергии.
В чем разница между FCFF и FCFE?
И какие ставки для них?
FCFF (Unlevered) — для ВСЕХ инвесторов. Дисконт = WACC. Дает EV.
FCFE (Levered) — только для АКЦИОНЕРОВ. Дисконт = Cost of Equity. Дает EqV.
